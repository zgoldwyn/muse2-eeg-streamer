# Contributor Bootcamp

This exercise is a quick low risk bootcamp on git and github workflow before we begin actual work on the project. 

## Goal

Create a short introduction file on your own branch, commit it, push the branch, and open a pull request for review.

## Exercise

1. Clone this repository.
2. Make sure your local `main` branch is current.
3. Create a branch named `bootcamp/<your-name>`.
4. In this directory, create `<your-name>.md` using lowercase letters and hyphens.
5. Add the template below and answer each prompt.
6. Commit the file with a clear message.
7. Push your branch and open a pull request into `main`.
8. Ask a teammate to review it. Respond to feedback before it is merged.

```markdown
# Your Name

- GitHub username:
- Operating system:
- One technical area I want to practice:
- One question I have about this project:
```

## Completion Check

The exercise is complete when:

- only your introduction file appears in the pull request;
- the file renders correctly on GitHub;
- another team member has reviewed the pull request; and
- you can explain the difference between a branch, commit, push, pull request, and merge.

## Team Rules

- Use one branch and one pull request per task.
- Pull the latest `main` before starting new work.
- Do not commit `.DS_Store`, virtual environments, build outputs, recordings, credentials, or participant data.
- Never force-push to `main`.
- Ask for help early when setup or merge problems block you.
